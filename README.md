# Deccan Routes site

React and Vite website for taxi bookings and local tours in Sambhaji Nagar.

## Start locally

```sh
npm install
npm run dev
```

## Owner setup before publishing

Update `src/config.js` with the confirmed business name, phone and WhatsApp numbers, email, address, coordinates, site domain, fleet specifications and rates, package rates, hours and social links. Replace the sample `example.com` domain in `public/robots.txt` and `public/sitemap.xml` with the live site domain. Leave rates blank until confirmed; the fare estimator then asks visitors to contact the business.

Destination distances are approximate from central Sambhaji Nagar. Several destination photographs are from Wikimedia Commons; their attribution links appear on the cards and hero. Vehicle photographs use relevant Unsplash stock images.
